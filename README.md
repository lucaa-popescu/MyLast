# MyLast

This project runs text-file-based approach of a shell script which shows us the behaviour of system commands such as "last" and "lastb".

It provides us a great and clear view of both successful logins and failed attempts for the grant of system security, the use of the '-n' flag offers good control over displayed information and the use of 'zgrep' processes data without a high amount of memory consumption, obtaining relevant columns such as user, terminal, date and time using the awk tokenization engine.
